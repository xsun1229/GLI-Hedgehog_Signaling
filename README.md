# GLI-Hedgehog_Signaling

A [workflowr][] project summarizing the GLI–Hedgehog signaling ×
neurodevelopmental-disorder gene-set enrichment analysis.

Analysis code and data live in the companion `GLI-Hedgehog_Signaling` analysis
project; the pages in `analysis/` read results from there.

Build (on Midway3): `module load pandoc`, then in R from this directory
`workflowr::wflow_build()`.

[workflowr]: https://github.com/workflowr/workflowr
